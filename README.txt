Files:
- index.html: responsive public profile page with Person/ProfilePage structured data.
- profile-photo.jpg: your supplied portrait, prepared for the profile page.

BEFORE PUBLISHING
1. Open index.html and replace YOUR-USERNAME in the canonical, og:url, og:image and JSON-LD URLs after you know your GitHub username.
2. Replace ADD-LINKEDIN-PROFILE-URL and all ADD-* contact/social placeholders with verified public URLs.
3. Confirm the education description and add verified achievements, dates and previous roles.
4. Add your professional photo as profile-photo.jpg.
5. Do not publish private contact details.

PUBLISH USING GITHUB PAGES
1. Create or sign in to a GitHub account.
2. Create a public repository named exactly USERNAME.github.io (replace USERNAME with your GitHub username).
3. Upload index.html and profile-photo.jpg to the repository root.
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then save.
5. Your site should appear at https://USERNAME.github.io after deployment.
6. In Google Search Console, add/verify the site and use URL Inspection to request indexing.

Google can take several days or longer to crawl and index a new page. Publication does not guarantee indexing or a Knowledge Panel.
